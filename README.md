# 一咕（EATG）谷子管家 APP

个人谷子（二次元周边）收藏管理与行情参考工具 · PWA 本地版

> 个人自用 · 纯本地离线 · 无需账号 · 无需服务器 · 无社交功能

## 功能

- **收藏库**：谷子款档案（图片/自定义选项/快捷字词）、购入记录（同款多笔、价格未知与估算）、订单与邮费分摊（按件均摊/按金额比例/手动指定、打包订单、账目平衡校验）、卖出记录与卖出订单（双区域、收入分摊、盈利计算）、定尾/全款预售管理与状态流转
- **角色图鉴**：预置长崎素世，三态收集进度，随收藏自动点亮
- **市场行情**：手动录入、价格走势、估值参考
- **统计**：总览指标、分布图表、盈利排行（已填写/估算/未知分开统计，另有总统计）
- **资讯**：发售资讯流（一期手动添加+RSS占位，自动抓取二期）
- **数据管理**：JSON/CSV 导出、完整备份与恢复

## 运行方式

无需构建，任选其一：

1. 直接双击 `index.html`（部分浏览器限制 IndexedDB，建议用方式2）
2. 本地服务器：在项目目录执行 `python -m http.server 8000`，浏览器打开 `http://localhost:8000`

## 目录结构

```
app/
├── index.html          入口
├── css/main.css        全局样式（MYGO主题）
├── js/
│   ├── storage.js      IndexedDB 数据层唯一入口
│   ├── agg.js          聚合统计
│   ├── utils.js        工具（金额/汇率/图片压缩）
│   ├── ui.js           全局UI组件（Toast/弹窗/角标）
│   ├── app.js          路由与启动
│   └── pages/          各页面逻辑
└── docs/               开发规范文档（数据字典/业务规则/页面规范/验收清单/开发指南/交付说明）
```

## 数据与隐私

- 全部数据仅存浏览器本地（IndexedDB + localStorage），无任何上传请求
- 图片导入时自动压缩并剥离 EXIF
- 备份/恢复：数据管理页一键导出 JSON/CSV 或完整备份（含图片）

## 技术说明

- 纯前端 PWA：原生 HTML/CSS/JavaScript（ES6+），无框架、无构建工具、无后端
- 金额以“分”为单位的整数存储，避免浮点误差
- 资讯自动监控（X/官网）依赖服务端抓取，属二期规划；一期为手动添加+RSS占位
