> 本文件是**让 AI 无错误开发本项目的总执行手册**。用法：
> 1. 每轮与 AI 开始对话时，先粘贴【第1节·统一开头提示词】（固定不变，减少上下文漂移）；
> 2. 然后按【第2节】顺序逐步发送分步提示词（每次只发一步，等 AI 完成并自验后再发下一步）；

## 1. 统一开头提示词（每轮会话第一句原样粘贴）

> （你是资深全栈工程师，正在协助我开发《一咕（EATG）谷子管家APP》个人谷子收藏管理工具（个人自用、纯本地离线、无需账号、无需服务器、无社交功能）。
> 项目代码位于：D:\codex\codex-data\GZ\app\
> 开工前必读（按此顺序，先全部读完再动手）：
> - docs/一咕EATG-详细开发指南.md（本次开发唯一执行基线）
> - docs/一咕EATG-数据字典与存储规范.md（数据层唯一基准）
> - docs/一咕EATG-业务规则与计算逻辑.md（金额/分摊/盈利/状态/统计口径唯一基准）
> - docs/一咕EATG-页面线框与UI规范.md（界面结构与视觉唯一基准）
> - docs/一咕EATG-验收测试清单.md（每步验收与最终交付唯一基准）
> 约束：
> 1. 技术栈固定：纯前端 PWA 单页应用，原生 HTML+CSS+JavaScript（ES6+），禁止引入框架、构建工具、后端依赖；hash 路由（#/library 等）；数据用 IndexedDB + localStorage；图表用 Canvas 自绘（禁用需联网的 CDN）。
> 2. 数据规范：所有数据操作必须走 storage.js 封装（initDB/add/put/get/getAll/del/query/bulk/count），禁止页面直接操作 IndexedDB；金额一律以“分”为单位的整数存储；日期格式 YYYY-MM-DD；图片压缩后 base64 存 IndexedDB 并剥离 EXIF，禁止进 localStorage。
> 3. 业务口径：邮费分摊（按件均摊/按金额比例/手动指定/未分摊）与卖出收入分摊算法、盈利公式（filled/estimated/unknown 三档严格区分）、状态机（deposit_pre→full_pre→shipping→on_hand→sold_out）、统计口径（已填写/估算/未知分开统计，另有总统计）一律以《业务规则与计算逻辑》为准，禁止自行发明。
> 4. 隐私与网络：全部数据仅存本机，禁止任何上传请求、外链资源、分析SDK；资讯监控一期仅手动添加+RSS占位，X/官网自动抓取属二期，不得在本期实现。
> 5. 改动纪律：改动前先说明改动点与影响面，完成后给出验证方式；只做我点名的步骤/模块，未点名内容一律不动；删除类操作必须二次确认；恢复备份前自动备份当前数据。
> 6. 每步完成后必须交付：本步实现清单 + 关键代码位置 + 如何手工验证 + 对应需求编号（FR-xx/L-xx/O-xx 等）。
> 7. 当前代码状态基线：目前项目目录为空或仅有上一步产物；每步只交付本步内容，不提前实现后续步骤；提交/生成文件前先列出将要创建/修改的文件清单。
> 8. 出错处理：任何一步报错或浏览器控制台有 warning/error，先停下说明根因与修复方案，再继续；不得静默跳过错误继续堆代码。）

## 4. 常见错误与规避（减少出错）

| 错误 | 规避方法 |
|---|---|
| 浮点金额 | 一律分整数存储，换算只在展示层（fmtMoney） |
| 直接裸操 IndexedDB | 全部走 storage.js，页面只调用封装 |
| 分摊尾差不处理 | 尾差并入最后一件并 Toast 提示 |
| 卖出不同步扣减 | 卖出/删除必须在 storage.js 事务内同时改两个表 |
| 统计口径混算 | 已填写/估算/未知严格三档，总统计必须标注“含估算” |
| 图片进 localStorage | 图片只能进 IndexedDB，压缩+剥EXIF |
| 状态机乱跳 | 状态角标菜单按合法流转表生成，禁止自由跳转 |
| 异步未 catch | 每个 await 包 try/catch，失败 Toast 且不静默 |
| 导出格式错 | JSON 头含 app/version；金额为分并注明单位 |
| 恢复覆盖数据 | 恢复前先自动备份当前数据为 .pre-restore-时间戳 |

## 5. 技术选型说明（为什么是PWA本地版）

- 本项目是个人自用、单机离线工具，PWA 单页应用**无需安装环境、无需上架、AI 一次做对的概率最高、可随时改**，符合“让 AI 没有错误地做出来”的目标。
- PRD 第9章的 Flutter 跨端方案保留为**原生APP升级版**：当需要 iOS 桌面图标+系统级体验时，按同一数据字典迁移（IndexedDB 结构一一对应 SQLite），升级成本可控。
- 资讯自动监控（X/官网）依赖服务端抓取，属二期；一期以手动添加+RSS占位闭环，避免不稳定的网络依赖导致交付失败。
