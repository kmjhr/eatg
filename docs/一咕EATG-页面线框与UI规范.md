# 一咕（EATG）谷子管家APP · 页面线框与UI规范

> 本文档是 AI 开发时的**界面结构与视觉唯一基准**，与《一咕EATG-详细开发指南.md》配套使用。
> 实现形态：PWA 单页应用（SPA）。路由：hash 路由（`#/library`、`#/gallery`、`#/market`、`#/news`、`#/mine` 等）。
> 所有页面必须同时覆盖：正常态、空态、加载态（骨架屏）。

---

## 1. 设计Token（CSS变量，全局唯一）

```css
:root {
  --bg: #FFFFFF;            /* 页面底色 */
  --card: #FFFFFF;          /* 卡片底色 */
  --ink: #1A1A1A;           /* 主文字 */
  --ink-2: #616161;         /* 次级文字 */
  --ink-3: #8E8E8E;         /* 占位/禁用 */
  --line: #E8E8E8;          /* 分割线 */
  --fill: #F5F5F5;          /* 浅灰底 */
  --accent: #FFDD88;        /* 素世暖黄：选中态/重点/盈利正数/进度 */
  --danger: #E74C3C;        /* 删除/亏损 */
  --success: #27AE60;       /* 到手/盈利 */
  --warn: #E67E22;          /* 定尾预售/待办 */
  --info: #2E86C1;          /* 全款预售 */
  --shipping: #8E44AD;      /* 在途 */
  --soldout: #95A5A6;       /* 已出荷 */
  /* 成员色（角色标签） */
  --m-tomori: #E64545;      /* 高松灯 */
  --m-anon: #F5A0C0;        /* 千早爱音 */
  --m-rana: #5B9BD5;        /* 要乐奈 */
  --m-taki: #9B59B6;        /* 椎名立希 */
  --m-soyo: #FFDD88;        /* 长崎素世 */
  /* 尺寸 */
  --radius-card: 12px;
  --radius-img: 8px;
  --pad-page: 16px;
  --gap: 8px;
  --tab-h: 56px;
  --nav-h: 48px;
}
```

- 单屏强调色（--accent）面积 ≤ 15%。
- 深色模式：`html[data-theme='dark']` 反转底色与文字（--bg:#121212、--card:#1E1E1E、--ink:#F5F5F5、--ink-2:#BDBDBD、--line:#2E2E2E），强调色与状态色不变。

## 2. 全局组件（必须统一实现）

| 组件 | 规范 |
|---|---|
| 底部Tab栏 | 固定底部，5项：收藏库/图鉴/行情/资讯/我的；图标线性2px描边+文字；选中项 `--accent` 高亮+加粗 |
| 顶部导航栏 | 高48px，左标题/右操作；返回箭头（二级页） |
| 卡片 | 白底、圆角12px、1px浅灰描边或浅阴影；内边距12px |
| 状态角标 | 胶囊形（border-radius:999px），白字11px，按状态着色（定尾--warn/全款--info/在途--shipping/到手--success/已出荷--soldout） |
| 主按钮 | 黑底白字（--ink 底）圆角8px 高44px；次按钮白底黑描边；危险按钮--danger底；禁用态--ink-3 |
| 输入框 | 高44px，圆角8px 1px描边；聚焦时描边变--ink |
| 筛选抽屉 | 底部半屏（max-height:70vh），多选标签+“重置/确定” |
| 确认弹窗 | 居中：标题+说明+取消/确认；危险操作为红色确认 |
| Toast | 底部2秒自动消失，成功/失败两种图标 |
| 空态 | 居中插画（素世剪影/谷子元素）+引导文案+主操作按钮 |
| 骨架屏 | 灰色块占位（--fill），列表加载时显示 |
| 数字 | 等宽数字（font-variant-numeric: tabular-nums），金额右对齐 |

## 3. 页面线框（结构与元素顺序）

### P01 启动页
- 居中：应用图标（圆形徽章：黑白摇滚色块+暖黄音符/鼓棒）、产品名“一咕（EATG）”、标语“记录每一件谷子”。
- 逻辑：initDB 完成 → 进入 `#/library`；失败显示“数据异常”+“去数据管理页”按钮。

### P02 收藏库首页（`#/library`）
结构顺序：
1. 顶部导航：标题“收藏库”+搜索框+筛选按钮+新增“+”按钮。
2. 统计摘要条（可横向滚动）：总件数/总投入/总盈利/在手/在途/未计价。
3. 分组切换器：“按谷子款 / 按订单”。
4. 谷子款卡片列表（默认）：
   - 左：96px方图（圆角8px，无图显示占位色块+类型文字）。
   - 右：名称（单行省略）· IP标签 · 角色标签 · 状态角标（右上）· 数量与金额（总数量、总投入、盈利绿/红）。
5. 订单分组视图：订单卡片（名称/日期/渠道/件数/实付总额），组内列出谷子缩略。
6. 左滑快捷：到手、转出；长按进入批量编辑（批量改状态）。
7. 空态：“还没有谷子，去添加第一件”。

### P03 谷子款详情页
1. 图片轮播（最多9张，点击全屏）。
2. 信息区：名称、IP/角色/类型标签、状态角标（点击弹状态流转菜单）、市场参考价。
3. 聚合区：总数量/总投入（含邮费）/均价/首次与最近购入价/累计盈利（估算标注）。
4. 购入记录时间线（日期倒序）：日期·数量·单价·邮费分摊·渠道·状态·价格状态；每条可点编辑；“+新增购入记录”。
5. 卖出记录区块：日期·卖价·手续费·实收·盈利（估算标注）；“+新增卖出记录”；批量卖出跳转卖出订单。
6. 行情区块：最近行情+走势缩略；“+添加行情”跳转 `#/market/add?goods_id=xx`。
7. 底部操作：编辑、删除（二次确认）。

### P04 新增/编辑谷子页（`#/goods/edit?mode=add|edit&id=&from=order|news`）
1. 谷子款表单：名称、IP（下拉+新增自定义）、角色（多选+新增）、类型（下拉+新增）、图片九宫格（拍照/相册）、市场参考价、标签、备注。
2. 购入记录表单：日期、数量、本体单价（可空）、币种、邮费分摊、渠道、状态、价格状态、备注。
3. 定尾预售扩展区（状态=定尾预售时显示）：定金、尾款、补款截止、到期提醒。
4. 快捷词面板：各输入框旁“快捷词”按钮（从 localStorage 取词）。
5. 连续录入开关：开启后保存不清空表单。
6. 从订单/资讯进入时自动预填。

### P05 购入记录编辑页
- 关联谷子款（只读/可换）、关联订单（可选）；表单同 P04 购入记录区。
- 从订单进入时 shipping_share 只读（回订单调整）。
- 保存/删除。

### P06 订单列表页（`#/orders`）
- 顶部：标题+“+新增订单”。
- 筛选：渠道、时间。
- 订单卡片：名称/日期/渠道/本体合计/邮费/实付总额/件数/状态；点击进详情。
- 批量到手：勾选订单→批量置 on_hand。

### P07 订单详情/新建订单页（`#/order/edit?id=|new`）
1. 订单信息：名称、日期、渠道、订单截图、备注。
2. 金额区：本体合计、邮费、实付总额（自动=合计+邮费）。
3. 分摊设置：模式单选（按件均摊/按金额比例/手动指定/未分摊）+“应用”按钮；打包订单开关（is_bundle）与本体拆分模式。
4. 谷子清单：每件=谷子名称/数量/本体金额（打包可空）/邮费分摊/小计；添加谷子（选已有或新建）、移除、逐件微调分摊。
5. 校验提示：平衡校验结果（√ 或 红色差异提示）；不平衡阻止保存。
6. 保存/删除（二次确认）。

### P08 卖出订单列表/详情/新建页（`#/sales`、`#/sale/edit?id=|new`）
1. 列表：卖出订单卡片（名称/日期/渠道/总售价/手续费/邮费/实收/盈利合计）。
2. 新建：名称、日期、渠道、总售价、总手续费、总邮费、币种、分摊模式（按件均摊/按售价比例/手动指定/未分摊）。
3. 详情：明细清单（谷子/数量/售价/手续费/邮费/实收/盈利），逐件微调分摊，校验实收平衡。
4. 从“现货在手”谷子批量发起：勾选→选择对应购入记录→生成草稿。

### P09 图鉴首页（`#/gallery`）
1. 角色横滑条：头像+名称，右上“+添加角色”；默认素世居中选中。
2. 进度区：大图/名称/所属IP/进度（已拥有/总数）+进度条（--accent填充）。
3. 图鉴网格（两列）：三态卡片（彩色亮显+拥有角标 / 半亮+状态角标 / 灰剪影+置灰名称）；按系列分组/搜索。
4. 条目点击：查看详情+“去收藏库补录”；手动切换拥有状态。
5. 空态/无数据引导。

### P10 图鉴条目编辑页
- 表单：所属角色、名称、系列、发售日期、图片、拥有状态、关联谷子款（可选）。
- 保存/删除（二次确认）。

### P11 行情首页（`#/market`）
1. 顶部：标题+搜索+“+录入”。
2. 列表：谷子名/平台/最近价格/日期/品相，按最近更新倒序。
3. 估值汇总条：市价总值、已估值件数（可选）。
4. 卡片快捷：想买/已订（联动资讯与收藏库）。

### P12 行情详情页（`#/market/detail?goods_id=`）
1. 信息区：名称、IP/角色、当前估值（标注“非交易指导价”）。
2. 走势图：Canvas 折线（时间横轴、价格纵轴），显示来源与日期；同一谷子多条行情。
3. 历史明细列表：平台/价格/品相/日期/备注，可编辑删除。
4. “+录入新行情”。

### P13 行情录入页（`#/market/add?goods_id=`)
- 表单：谷子（关联或自由输入）、平台、价格、品相、记录日期、备注；保存。

### P14 资讯首页（`#/news`）
1. 顶部：标题+筛选+监控源设置（右上）+“+手动添加”。
2. 筛选：IP/角色/类型；只看未读。
3. 资讯卡片流：图/名称/IP角色/开订时间/出荷时间/参考价/渠道；三按钮：想买/已订/忽略；左滑快速忽略；未读圆点。
4. 愿望清单入口。

### P15 资讯详情/手动添加页
- 详情：大图+完整信息+原文链接（无链接则隐藏）+三操作。
- 手动添加：标题、图片、IP、角色、类型、开订、出荷、参考价、渠道、备注。

### P16 监控源配置页（`#/sources`）
- 列表：名称/地址/类型/启用开关/抓取频率；新增/编辑/删除。
- 预置：BanG Dream!官网、武士道官方通贩、官方X、游戏官网（enabled 默认关，二期启用）。
- 说明条：一期仅手动添加+RSS占位；X/官网自动抓取二期。

### P17 愿望清单页（`#/wishlist`）
- 列表：想买谷子（名称/IP角色/开订/出荷/参考价），按开订时间排序。
- 操作：标记已订（转收藏库）、移除、编辑提醒时间。

### P18 我的首页（`#/mine`）
- 头部：产品名/版本号/收藏概览（件数/投入/盈利）。
- 功能入口列表：统计、订单、卖出订单、数据管理、设置、关于。

### P19 统计页（`#/stats`）
1. 总览卡片：总花费/总件数/在手/在途/市价总值/邮费合计/未计价/总盈利/估算盈利。
2. 口径切换：“分开统计（已填写/估算/未知）”默认 / “总统计（含估算）”。
3. 图表区（Canvas）：IP占比环形、类型占比环形、状态占比环形、月度花费柱状、月度邮费占比。
4. 盈利排行：维度切换（谷子款/角色/IP），亏损标红，点击看明细。

### P20 设置页（`#/settings`）
- 分组列表：币种（默认币种/汇率手动/自动换算开关）、提醒（开关/提前量/免打扰时段）、图片（占用统计/清理缓存/压缩质量）、监控源（入口）、数据管理（入口）、关于（入口）。

### P21 数据管理页（`#/data`）
- 导出区：维度多选（谷子款/购入记录/订单/卖出记录/卖出订单）+“导出JSON/导出CSV”。
- 备份区：完整备份（含图片）/最近备份时间/自动备份提醒开关。
- 恢复区：选择备份文件/导入；恢复前自动备份当前数据。
- 说明：数据仅存本机。

### P22 关于与隐私页（`#/about`）
- 品牌区：图标/名称/版本。
- 隐私说明：数据仅存本机、不上传；图片剥离EXIF；网络请求不含收藏数据。
- 致谢：MyGO!!!!!、BanG Dream! 等IP致谢与免责声明（本工具与官方无隶属关系）。

## 4. 图鉴三态视觉（明确实现）

| 状态 | 样式 |
|---|---|
| 已拥有 | 彩色图（原图）、左上“拥有”角标（--accent底黑字）、右下获取方式 |
| 已拥有未出荷 | 图 opacity:0.7、显示状态角标（预售/在途色）、文字半透明 |
| 未拥有 | 图置灰（grayscale(1) opacity:0.45）、名称--ink-3、“未拥有”文字 |
| 点亮动画 | 状态切换 300ms 过渡：grayscale→color + 暖黄扫光（可选 clip-path 动画） |

## 5. 文案规范（避免歧义）

| 场景 | 文案 |
|---|---|
| 空态-收藏库 | “还没有谷子，去添加第一件” |
| 空态-图鉴 | “还没有图鉴条目，去添加官方谷子” |
| 未知价格 | “价格待分” / “成本未知，暂不计盈利” |
| 估算 | 数字旁标注“估算” |
| 估值 | “非交易指导价” |
| 删除确认 | “删除后不可恢复，建议先导出备份，确认删除？” |
| 汇率过期 | “汇率可能过期（最近更新：日期）” |
| 分摊尾差 | “尾差已并入最后一件” |
| 资讯受限 | “网络受限，可手动添加” |
