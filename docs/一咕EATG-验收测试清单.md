# 一咕（EATG）谷子管家APP · 验收测试清单

> 本文档是 AI 开发时**每步验收与最终交付的唯一测试基准**。
> 每完成一个开发步骤，先跑对应模块用例，全部通过再进入下一步；最终交付前跑完整清单。
> 金额用例中“分”与“元”换算：1元=100分。

---

## 0. 测试准备

- 用浏览器（Chrome/Edge 无痕窗口）打开应用，F12 → Application → IndexedDB 确认 `eatg_db` 已建。
- 准备 3 张测试图片（jpg/png，各约1~3MB）。
- 每轮测试前可用“数据管理 → 恢复”导入固定种子数据，或手工录入用例数据。

## 4. 卖出与盈利（重点）

| 编号 | 用例 | 步骤 | 期望结果 |

| S-01 | 单件卖出 | 现货谷子卖出1件，价50元，手续费1元，邮费0 | 实收=4900分；购入成本=本体+邮费分摊；盈利=实收-成本 正确 |
| S-02 | 数量校验 | 卖出数量 > 剩余可卖 | 阻止保存并提示剩余数量 |

| S-07 | 卖出订单平衡 | 手动改某件实收使Σ≠net_total | 阻止保存并高亮 |

| S-10 | 双区域互跳 | 卖出订单详情↔谷子款详情 | 互相跳转正常，数据一致 |
